# Architecture Overview

This document sketches the planned structure for the Ark Angel project. The system will be organized into several key modules:

- **Ingestion**: handle data intake from external sources and normalize incoming formats.
- **Enrichment**: apply rules and lookups to enhance collected data with additional context.
- **AI Analysis**: leverage machine learning and language models to interpret and summarize information.
- **Geo**: manage geographic processing, including coordinates, regions, and mapping utilities.
- **Case Management**: track cases, tasks, and workflows across the lifecycle of an investigation.
